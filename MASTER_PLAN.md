### Фаза 1 — форк на Титане (мост до своего приложения)

- **Цель фазы:** патченая сборка приложения Tribit стоит на Титане и проходит `testcases/TC_fork_titan.md`.
- **Шаги:** пересобрать (`bash build.sh`: сборка собрана до патча 6); патч 7 — вторая проверка геолокации в библиотеке
  `com.bhm.ble` (`setNeedCheckGps(true)` в `TribitApp`); установка после слова владельца об удалении оригинала; прогон
  15 случаев и одного контрольного случая из `TC_fork_titan.md`.
- **Статус:** 🔲 ждёт владельца: нужна ли эта фаза теперь, когда выбрано своё приложение, и можно ли удалить оригинал.

### Фаза 2 — своё приложение: ядро

- **Цель фазы:** приложение Krinik Tribit находит StormBox Blast 2 без геолокации, подключается, меняет громкость и
  эквалайзер, показывает заряд батареи колонки; интерфейс целиком виден на Титане.
- **Шаги:** эпик по лестнице `/plan-epic` — разведка (протокол из кода, практика приложений для BT-колонок, выбор
  стека: предлагается Kotlin + Compose, как в KARTUN), мета-план, операционный план первой фазы. Транспорт для
  StormBox Blast 2 (RFCOMM или BLE) пока не известен — его выяснит разведка.
- **Статус:** 🔲

### Фаза 3 — своё приложение: для людей

- **Цель фазы:** переводы (английский, русский, затем языки из `researches/02_languages.md`), альбомная ориентация,
  «О приложении» со ссылками на GitHub, релиз в GitHub по слову владельца — один подписанный universal APK для
  64-битных устройств, который ставится и работает сразу.
- **Шаги:** по плану фазы, когда закроется фаза 2.
- **Статус:** 🔲
