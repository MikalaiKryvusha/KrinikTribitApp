## Вектор цели

**Достичь** (Achieve): пользователь сохраняет настройки эквалайзера и подсветки колонки в файл JSON в памяти телефона,
открывает такой файл (свой или присланный другом) и получает те же настройки на своей колонке. Облака нет: файл —
единственный способ перенести и поделиться (облачная копия эквалайзеров выпиливается, слово владельца 2026-10-16).

## Критерии приёмки

[AI]
1. На экране эквалайзера есть «Экспорт»: файл `*.json` появляется в папке «Загрузки» телефона; в нём имя пресета и
   значения всех полос.
2. «Импорт» открывает системный выбор файла; после выбора файла из п. 1 на другом телефоне полосы эквалайзера равны
   полосам из файла, пресет есть в списке после перезапуска приложения.
3. То же для подсветки (режим, цвет, яркость — какие поля есть у колонки, покажет разведка протокола).
4. «Поделиться» отдаёт файл системному меню отправки (мессенджер, почта).
5. Файл чужой модели или битый файл не применяется: приложение говорит, что не так, и не падает.
[/AI]
