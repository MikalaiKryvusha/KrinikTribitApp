## Вектор цели

**Боль.** Официальное приложение Tribit требует геолокацию и аккаунт, следит за пользователем через Firebase и свой
сервер, падает на своём эквалайзере и обрезает экраны (`GOAL.md`, `researches/01`, `researches/03`). Чинить их код дорого:
smali, 2 006 классов, протокол без проверки пакетов (`researches/10`, `researches/11` §5).

**Куда идём (Achieve).** Своё приложение `app/` (Kotlin + Compose) управляет StormBox Blast 2 без геолокации, без аккаунта
и без сервера Tribit; дизайн и скорость — как у KARTUN; один подписанный universal APK в GitHub. Модели и прошивку, которых
своё приложение ещё не умеет, до тех пор обслуживает запасной путь — починенный Tribit (`com.kriniks.tribit.old`).

**Почему с нуля и по шагам.** Решение владельца 15:24 (журнал `MASTER_PLAN.md`). Порядок слоёв — как у зрелых открытых
приложений для аудиоустройств: транспорт · кодек протокола · модель устройства · интерфейс, подменный транспорт и тесты
пакетов байт в байт на JVM (OpenSCQ30, Gadgetbridge, FreeBuddy — `researches/11` §4.4).

## Критерии приёмки эпика

1. **Колонка без геолокации.** Ситуация: на A51 (Android 13) геолокация выключена, Blast 2 сопряжена и включена. Действие:
   пользователь открывает Krinik Tribit. Результат: на главном экране карточка «Tribit StormBox Blast 2» с зарядом в
   процентах; приложение не спрашивает разрешение на геолокацию. Проверка: `adb shell dumpsys package com.kriniks.tribit.debug
   | grep -i location` — пусто; снимок экрана в отчёте прогона `testcases/reports/`.
2. **Главный путь целиком.** Громкость, воспроизведение, эквалайзер (пресеты и свой), подсветка, настройки колонки меняются
   из приложения, и колонка отвечает. Проверка: строка инвентаря фазы 1 «функция → ответ колонки в журнале debug» для каждой
   функции — pass.
3. **Протокол под тестами.** Scale: команды `researches/11` §3.3, на которые есть тест байт в байт · Meter:
   `.\gradlew.bat testDebugUnitTest` · Target: каждая команда, которую шлёт приложение.
4. **Быстрый холодный старт.** Scale: `TotalTime` в мс · Meter: `adb shell am start -S -W -n
   com.kriniks.tribit/.MainActivity` на A51, release · Target: не медленнее KARTUN на Титане (522 мс, `researches/11` §4a.7).
5. **Красота — решение владельца.** Макеты 2–3 вариантов на одном листе, выбор владельца записан в журнал (класс вкуса,
   `AGENT_GUIDE.md`).
6. **Релиз.** Подписанный universal APK release в GitHub Releases по слову владельца (`/release`).

Порядок: 1 → 2 → 3 → 4 → 5. Фаза 1 — фундамент: без связи нечего показывать. Фаза 2 закрывает главную боль отзывов

## Риски

- **(а) Высокий:** колонка не отвечает на наш пакет, хотя код Tribit читается так же (команда «Blast trad» 8 против 9 уже
  расходится, `researches/11` §3.3). Защита: debug пишет в журнал каждый пакет туда и обратно; тест кодека строится на
  пакетах, пойманных с настоящей колонки.
- **(а) Высокий:** два ответа приходят одним чтением, и их приложение разбирает их как один (`researches/11` §3.1). Защита:
  наш читатель режет поток по длине пакета и проверяет контрольную сумму; на это есть тест.
- **(б) Средний:** SPP занят приложением Tribit, если оно открыто на том же телефоне. Защита: подсказка «закройте другое
  приложение колонки» при отказе `connect()`; проверка на A51 с открытым `com.kriniks.tribit.old`.
- **(б) Средний:** `connect()` блокирует до ≈ 12 с. Защита: только вне главного потока, `cancelDiscovery()` до него,
  `close()` всегда.
- **(в) Низкий:** другое написание имени «TRIBIT StormBox Blast 2» — сравнение без учёта регистра.
