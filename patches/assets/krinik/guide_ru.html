KRINIK TRIBIT

Приложение Tribit с исправлениями: без аккаунта, без Firebase, без геолокации.

1Подключение колонки

  1. Включите колонку и Bluetooth на телефоне.
  2. Откройте Krinik Tribit и нажмите «START».
  3. Разрешите доступ к устройствам поблизости: без него телефон не найдёт колонку по Bluetooth. Геолокацию приложение не просит.
  4. На главном экране нажмите «Tap to Add Device» и выберите свою колонку.

2Эквалайзер

На странице колонки откройте «Sound Effects». Чтобы создать свой эквалайзер, нажмите «New Custom». Имя эквалайзера — до 15 символов.

Имя колонки (до 25 символов) меняет строка «Имя устройства» в настройках колонки: шестерёнка на странице колонки.

3Прошивка колонки

Приложение проверяет прошивку, когда вы нажимаете строку «Версия прошивки» в настройках колонки. После нажатия приложение спросит сервер Tribit, есть ли новая прошивка для этой модели, и покажет ответ.

4Приватность

Krinik Tribit уважает приватность пользователя и GDPR. Сервер Tribit не может установить личность человека.

Гость — это вход на сервер Tribit без аккаунта и без данных человека. Приложение работает так:

  • аккаунта нет — приложение входит на сервер Tribit анонимным гостем;
  • ID гостя, модель телефона и версия Android в запросах случайные: приложение выбирает их один раз и хранит до очистки данных приложения;
  • к серверу Tribit уходят только четыре вида запросов: вход гостя, каталог колонок, проверка прошивки и переводы строк интерфейса;
  • Firebase (аналитика с рекламным ID, Crashlytics, пуши) удалён из приложения.

5Новый анонимный гость

Чтобы приложение вошло на сервер Tribit другим гостем, очистите данные приложения в Android. После очистки приложение выберет новые случайные ID гостя, модель телефона и версию Android.

Настройки → Приложения → Krinik Tribit → Хранилище → Очистить данные

На телефонах Samsung раздел «Хранилище» называется «Память».

После переустановки приложение тоже входит другим гостем.
