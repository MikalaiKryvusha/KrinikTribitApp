### R8. Одна команда — одно действие (git)

1. `git add` вызывай отдельной командой.
2. `git commit -m "<сообщение>" -m "Co-Authored-By: …"` вызывай отдельной командой; сообщение пиши прямо в `-m`, не через
   `-F` из временного файла.
3. `git push` вызывай отдельной командой, ни с чем не склеивай.
4. Если классификатор авто-режима всё равно отказал одиночному действию — не повторяй и не обходи, скажи владельцу.
- **Исключение:** нет.
