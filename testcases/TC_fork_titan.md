# Test cases — патченая сборка Tribit 5.0.0 на Титане

**Created:** 2026-10-15 · **Under test:** патчи 1–7, 11, 17 (`patches/apply.py`), вариант debug · **Version/build:** Tribit 5.0.0 (versionCode 5000) + патчи · **Test basis:** `researches/03_tribit_app_pains.md`, слова владельца в чате 2026-10-15

> Проверка — это проход по приложению руками или через adb, с чтением результата: экрана, журнала,
> файла (`TESTING_FRAMEWORK.md`). Сборка собралась — это не проверка.
> Стенд: планшет HEADWOLF Titan 1, `adb -s 192.168.1.3:5555`, Android 16, 1600×2560, масштаб экрана
> 480 dpi поверх панели 320 dpi, язык русский; колонка Tribit StormBox Blast 2.
> Статусы случаев — в отчётах прогонов `testcases/reports/`.

## Прежде чем ставить

1. Собрать debug: `bash build.sh debug` → `out/KrinikTribit-debug.apk` (пакет `com.kriniks.tribit.debug`, «Debug Krinik
   Tribit»). Он встаёт рядом с оригиналом Tribit — удалять оригинал не нужно.
2. Поставить: `C:/Android/Sdk/platform-tools/adb.exe -s 192.168.1.3:5555 install -r out/KrinikTribit-debug.apk`
3. Очистить журнал падений: `adb -s 192.168.1.3:5555 logcat -c -b crash`; после прогона прочитать `logcat -d -b crash`.
4. Поднять UI-агента (`HOUSE_RULES.md` §6): `python C:\Android\private\ui-agent\ui.py --serial 192.168.1.3:5555 --start ping`.

## Чем смотреть

- Экран и касания — UI-агентом (`HOUSE_RULES.md` §6): `wait <текст>`, `tapText <текст>`, `labels`, `tree`, `shot <файл>`.
- Снимок для отчёта — в WebP: `adb exec-out screencap -p | magick png:- -resize 500x -quality 80 <файл>.webp`.
- Касание только когда сверху наш пакет: `adb shell dumpsys activity activities | grep topResumedActivity` содержит
  `com.kriniks.tribit.debug`.
- Падения: `adb -s 192.168.1.3:5555 logcat -b crash -d`.

## Куда писать результат

Отчёт о прогоне: `testcases/reports/<дата>_<что гоняли>.md` — что гоняли, какими командами, что
прочитали, что нашли, вердикт. Случай без статуса (прошёл / не прошёл / заблокирован) не считается
проверенным.
