# Test cases — патченая сборка Tribit 5.0.0 на Титане

**Created:** 2026-10-15 · **Under test:** патчи 1–6 (`patches/apply.py`) · **Version/build:** Tribit 5.0.0 (versionCode 5000) + патчи · **Test basis:** `researches/03_tribit_app_pains.md`, слова владельца в чате 2026-10-15

> Проверка — это проход по приложению руками или через adb, с чтением результата: экрана, журнала,
> файла (`TESTING_FRAMEWORK.md`). Сборка собралась — это не проверка.
> Стенд: планшет HEADWOLF Titan 1, `adb -s 192.168.1.3:5555`, Android 16, 1600×2560, масштаб экрана
> 480 dpi поверх панели 320 dpi, язык русский; колонка Tribit StormBox Blast 2.
> Все случаи сейчас `[NOT-TESTED]`: сборка на устройство ещё не ставилась.

## Прежде чем ставить

1. Пересобрать: `bash build.sh` — текущий APK собран до патча 6.
2. Удалить оригинал (ждёт слова владельца — подпись другая, рядом не живут):
   `adb -s 192.168.1.3:5555 uninstall com.thousandshores.tribit`
3. Поставить: `adb -s 192.168.1.3:5555 install-multiple out/signed/*.apk`
4. Открыть журнал в отдельном окне и держать его открытым весь прогон:
   `adb -s 192.168.1.3:5555 logcat -b crash -T 1`

## Чем смотреть

- Снимок экрана: `adb -s 192.168.1.3:5555 exec-out screencap -p > shot.png` (для README — в WebP,
  правило R4 проекта KARTUN).
- Нажатия: только когда наше окно на экране — иначе попадём в чужое приложение владельца
  (EXP-0024 проекта KARTUN). Проверка: `adb shell dumpsys window | grep mCurrentFocus` содержит
  `com.thousandshores.tribit`.
- Падения: `adb -s 192.168.1.3:5555 logcat -b crash -d`.

## Куда писать результат

прочитали, что нашли, вердикт. Случай без статуса (прошёл / не прошёл / заблокирован) не считается
проверенным.
