## Почему это важно / какую боль решает

[AI]Официальное приложение Tribit 5.0.0 падает при создании своего эквалайзера, требует геолокацию для поиска колонки,
обрезает экраны на планшете с увеличенным масштабом, не принимает символы в пароле, показывает тексты вперемешку на
английском и китайском (`researches/03_tribit_app_pains.md`). Из 2648 отзывов Google Play: не подключается к колонке —
366 отзывов, модель не поддерживается — 279 отзывов, вылетает — 159 отзывов, не удаётся зарегистрироваться —
126 отзывов, эквалайзер не сохраняется — 117 отзывов (`researches/01_play_reviews.md`).[/AI]

## Как выглядит успех

[AI]
1. Krinik Tribit — приложение Tribit с нашими исправлениями — не падает: создание своего эквалайзера и остальные экраны
   проходят без вылета.
2. Колонка находится и подключается без включённой геолокации.
3. Интерфейс целиком виден на планшете при любом системном масштабе и в альбомной ориентации.
4. Все тексты лежат в файлах ресурсов; тексты с сервера Tribit заменены нашими там, где они кривые; английский и русский
   переведены руками, дальше языки из `researches/02_languages.md`.
5. На экране «О приложении» стоят ссылки на GitHub Криника.
6. README написан на трёх языках: русском, английском и китайском (языки названы в `STATUS.md` коммита `bee2bd6`).
7. Пользователь скачивает один подписанный universal APK для 64-битных устройств, ставит и сразу пользуется. Где
   публикуется APK с кодом Tribit, решает владелец (вопрос в `STATUS.md`).
[/AI]
